WËR ASSET — Landing page SaaS (HTML / CSS / JS)

Fichiers
- index.html
- styles.css
- app.js
- assets/logo-full.png
- assets/logo-mark.png

Utilisation
1. Décompresser le ZIP.
2. Ouvrir index.html dans Chrome / Edge / Safari.
3. Pour une mise en ligne réelle, servir le dossier via un hébergeur statique (Vercel, Netlify, Cloudflare Pages, etc.).

Interactions incluses
- Header sticky + menu mobile
- Animations d'apparition au scroll
- Hero dashboard 3D interactif à la souris
- Démo produit en modal
- Parcours « Comment ça marche » interactif
- Onglets métiers/personas
- FAQ accordéon
- Formulaire de demande de pilote (démo front uniquement)
- Responsive desktop / tablette / mobile

Contenu métier utilisé
- QR-first
- identité numérique équipement
- maintenance préventive
- tickets / ordres de travail
- application technicien offline-first
- pièces & stock
- fournisseurs / SLA / garanties
- reporting coûts / TCO
- paliers Starter / Essentiel / Business / Entreprise
- pilote hôtelier Dakar

Note
Le formulaire est volontairement front-only : aucun email n'est envoyé.
Les montants de prix ne sont pas inventés, car ils doivent être validés après le pilote.
